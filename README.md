## What the App Does

Davis Student Resource Compass gives UC Davis students a guided way to find campus support. Its map-centered interface shows available resources geographically, while semantic matching helps connect a student's stated needs with services that may be relevant instead of returning an unfiltered list.

The responsive interface is designed for practical, inclusive access. It includes multilingual capabilities and accessibility-conscious navigation for use across different devices. Students, support personnel, and community contributors can use it to locate, review, and improve information about on-campus assistance.

---

## Core Capabilities

- Explore campus services through an interactive map
- Match descriptions of needs with applicable resources using semantic search
- Receive predictive recommendations for potentially useful services
- View real-time indicators for resource availability
- Add community-submitted resources and listing updates
- Access the application in multiple languages
- Navigate with accessibility support
- Use the responsive interface on a range of screen sizes

## Using the Compass

Start by opening the application and browsing the campus map or searching for a type of service. Semantic matching uses the meaning of the user's description to identify support options that may fit the situation.

A common session looks like this:

- Launch the application in a browser
- Search for a service or browse a category
- Examine recommended resources and their availability status
- Choose another language when required
- Submit a community update if resource information has changed or a new listing is needed

During local development, reload the browser after editing content or layout files to view the changes.
